# TransHover

Расширение для Chromium: перевод слова, предложения или абзаца под курсором через OpenRouter.

## Установка

1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
3. Откройте иконку расширения, вставьте API-ключ OpenRouter и сохраните.

## Использование

Наведите курсор на текст и нажмите клавишу:

| Клавиши | Что переводится |
| --- | --- |
| `Ctrl` | слово |
| `Ctrl + Shift` | предложение |
| `Ctrl + Shift + Alt` | абзац |

`Esc` или клик мышью скрывает подсказку.

## Настройки

- **Автоопределение эксперта** — модель сама выбирает стиль (литературный, экономический, медицинский, технический, общий).
- Если галочка снята — используется эксперт, выбранный в списке.
- **Дополнительный промпт** добавляется к системной инструкции модели.

Настройки хранятся в `chrome.storage.local` на этом компьютере.
